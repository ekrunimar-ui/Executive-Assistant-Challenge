# Daily Executive Workflow

## 8:00 AM — Morning Review

Review:

- Calendar
- Emails
- Travel
- Deadlines
- Meetings
- Urgent requests

Create the executive's Top 3 Priorities.

## 9:00 AM — Inbox Triage

Process emails according to:

1. Urgent
2. Important
3. Delegatable
4. Informational
5. Spam

## 10:00 AM–12:00 PM — Execution

Focus on:

- Scheduling
- Client communication
- Travel arrangements
- Follow-ups
- Business-critical requests

## Midday Review

Check:

- New urgent emails
- Calendar changes
- Travel updates
- Outstanding tasks

Re-prioritize when necessary.

## Afternoon

Complete:

- Follow-ups
- Routine administration
- Reports
- Scheduling
- Delegated-task monitoring

## End-of-Day Review

Prepare:

- Completed tasks
- Outstanding tasks
- Tomorrow's priorities
- Upcoming meetings
- Travel updates
- Items requiring executive decisions
